rag-project/
│
├── .env                        ← API keys
├── app.py                      ← Streamlit UI entry point
├── sample.pdf                  ← test PDF
│
├── config/
│   └── settings.py             ← all config variables (model name, chunk size etc.)
│
├── pipeline/
│   ├── loader.py               ← load + extract text from PDF
│   ├── splitter.py             ← split text into chunks
│   ├── embeddings.py           ← create embeddings + FAISS vectorstore
│   └── retriever.py            ← similarity search + fetch relevant chunks
│
├── llm/
│   └── generator.py            ← send chunks + question to LLM, get answer
│
├── utils/
│   └── helpers.py              ← any reusable utility functions
│
└── vectorstore/                ← FAISS index gets saved here (auto-created)



app.py → loader → splitter → embeddings → retriever → generator → answer
